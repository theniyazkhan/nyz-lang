========================================================================
                      SYLHETI LANGUAGE MANUAL (.syl)
========================================================================

Sylheti is a domain-specific programming language compiled and interpreted
using Flex and Bison. Sylheti features a unique Sylheti domain vocabulary
with support for right-associative exponentiation, logical operators, and loops.


1. PREREQUISITES & COMPILATION INSTRUCTIONS
===========================================

Prerequisites:
  - GCC (C compiler)
  - GNU Make
  - Flex (or win_flex)
  - Bison (or win_bison)

Compilation:
  Run the build command from the repository root directory:

    make

  This produces the executable `sylheti` (`sylheti.exe` on Windows).

Execution:
  Pass any valid `.syl` script file as an argument:

    ./sylheti examples/demo.syl
    ./sylheti examples/calculator.syl

Clean Build Artifacts:
  To remove temporary build files and executables:

    make clean


2. SYLHETI KEYWORD CHEAT SHEET
==============================

+-------------------+--------------------+-----------------------------------------------+
| Standard Concept  | Sylheti Keyword    | Example Syntax                                |
+-------------------+--------------------+-----------------------------------------------+
| Variable Decl     | dhoro              | dhoro x = 10;                                 |
| Print Output      | dekha              | dekha x;  OR  dekha "Hello\n";                |
| User Input        | ne                 | ne x;                                         |
| Conditional (If)  | jodi               | jodi (x > 0) { dekha x; }                     |
| Otherwise (Else)  | naile              | jodi (x > 0) { ... } naile { ... }            |
| While Loop        | ghuro              | ghuro (count > 0) { count = count - 1; }      |
| For Loop          | ghur               | ghur (dhoro i = 0; i < 5; i = i + 1) { ... }  |
| Boolean True      | hasa               | dhoro is_active = hasa;                        |
| Boolean False     | misa               | dhoro is_active = misa;                        |
| Logical AND       | ar                 | jodi (x > 0 ar y > 0) { ... }                 |
| Logical OR        | ernay              | jodi (x > 0 ernay y > 0) { ... }              |
| Logical NOT       | nabe               | jodi (nabe (x == 0)) { ... }                  |
+-------------------+--------------------+-----------------------------------------------+


3. FORMAL EBNF SYNTAX RULES
===========================

Program          ::= StatementList ;
StatementList    ::= { Statement } ;

Statement        ::= Declaration
                   | Assignment
                   | PrintStatement
                   | InputStatement
                   | JodiStatement
                   | GhuroStatement
                   | GhurStatement
                   | Block ;

Declaration      ::= "dhoro" IDENTIFIER [ "=" Expression ] ";" ;
Assignment       ::= IDENTIFIER "=" Expression ";" ;

PrintStatement   ::= "dekha" Expression ";"
                   | "dekha" STRING_LITERAL ";" ;

InputStatement   ::= "ne" IDENTIFIER ";" ;

JodiStatement    ::= "jodi" "(" Expression ")" Statement [ "naile" Statement ] ;
GhuroStatement   ::= "ghuro" "(" Expression ")" Statement ;
GhurStatement    ::= "ghur" "(" [ Declaration | Assignment | ";" ] Expression ";" [ Assignment ] ")" Statement ;

Block            ::= "{" StatementList "}" ;

Expression       ::= Expression "ernay" Expression
                   | Expression "ar" Expression
                   | Expression RelationalOp Expression
                   | Expression "+" Term
                   | Expression "-" Term
                   | Term ;

Term             ::= Term "*" Factor
                   | Term "/" Factor
                   | Factor ;

Factor           ::= Primary "^" Factor    (* Exponentiation: Right-Associative *)
                   | Primary ;

Primary          ::= INTEGER
                   | "hasa"
                   | "misa"
                   | IDENTIFIER
                   | "nabe" Primary
                   | "-" Primary
                   | "(" Expression ")" ;

RelationalOp     ::= "<" | "<=" | ">" | ">=" | "==" | "!=" ;


4. CODE SNIPPET EXAMPLES
========================

Example 1: Variable Declaration and Arithmetic
-----------------------------------------------
dhoro a = 5;
dhoro b = 3;
dhoro result = a ^ b;    // Calculates 5^3 = 125
dekha "Result of 5^3:";
dekha result;


Example 2: Interactive Input and Conditional Logic
--------------------------------------------------
dekha "Please enter your age:";
dhoro age;
ne age;

jodi (age >= 18 ar hasa) {
  dekha "Access Granted: Adult";
} naile {
  dekha "Access Restricted: Minor";
}


Example 3: Ghur (For Loop) Countdown
------------------------------------
ghur (dhoro i = 5; i > 0; i = i - 1) {
  dekha "Countdown:";
  dekha i;
}
