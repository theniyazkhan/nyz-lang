# nyz-lang

This folder contains a small compiler-style toy language built with Flex and Bison.

## Features
- Integer variables
- Assignment statements
- Arithmetic expressions
- `print(...)` output
- `while (...) { ... }` loops
- Block-based statements

## Build
Run the following from this directory:

```bash
make
```

The executable is named `nyz`.

## Run an example
```bash
./nyz examples/demo.src
```
