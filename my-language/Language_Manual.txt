Nyz Language Manual
===================

Syntax Overview
---------------
- Variable declaration:
  int name;
  int name = value;

- Assignment:
  name = expression;

- Output:
  print(expression);

- Loop:
  while (condition) statement

- Blocks:
  { statements }

Supported operators
-------------------
- Arithmetic: +, -, *, /
- Comparison: <, <=, >, >=, ==, !=

Example
-------
int x = 3;
print(x);
while (x > 0) {
  print(x);
  x = x - 1;
}

Compilation
-----------
Run the build command from the project directory:

make

Then execute a source file:

./nyz examples/demo.src
